# Helm Console Integration with Overmap

Эта система обеспечивает полноценное взаимодействие между helm console и overmap системой корабля.

## Основные возможности

### Навигация
- **Направленное движение**: 8-направленное управление (север, юг, восток, запад + диагонали)
- **Контроль скорости**: Регулируемый дроссель от 1% до 100%
- **Остановка**: Мгновенная остановка двигателей
- **Торможение**: Постепенное снижение скорости

### Информация о корабле
- **Позиция**: Текущие координаты X/Y на overmap
- **Скорость**: Текущая скорость в Gm/s
- **Курс и направление**: Отображение текущего курса
- **ETA**: Время до следующей клетки
- **Масса корабля**: Автоматический расчет на основе размера

### Радар и взаимодействие
- **Обнаружение объектов**: Автоматическое сканирование в радиусе сенсоров
- **Взаимодействие**: Кнопки для взаимодействия с обнаруженными объектами
- **Стыковка**: Возможность стыковки с планетами, станциями и другими кораблями

### Управление кораблем
- **Переименование**: Возможность изменить название корабля
- **Подключение**: Автоматическое подключение к кораблю в текущей области
- **Стыковка в пустом пространстве**: Создание временной стыковочной зоны

## Использование

### Для администраторов
1. Используйте команду `Create Test Ship` в категории Debug для создания тестового корабля
2. Команда `Create Test Planet` создаст тестовую планету для взаимодействия
3. Тестовый корабль автоматически создается с helm console на борту

### Для игроков
1. Найдите helm console на корабле
2. Откройте интерфейс - консоль автоматически подключится к кораблю
3. Используйте кнопки направления для движения
4. Регулируйте дроссель для контроля скорости
5. Взаимодействуйте с объектами через радар

## Технические детали

### Файлы системы
- `helm_console.dm` - Основная логика helm console
- `test_helm_integration.dm` - Тестовые объекты и админские команды
- `HelmConsole.tsx` - Интерфейс TGUI

### Состояния корабля
- `OVERMAP_SHIP_FLYING` - В полете, доступно управление
- `OVERMAP_SHIP_IDLE` - На стоянке/пристыкован
- `OVERMAP_SHIP_DOCKING` - Процесс стыковки
- `OVERMAP_SHIP_UNDOCKING` - Процесс отстыковки

### Интеграция с overmap
- Автоматическое обнаружение кораблей в области консоли
- Синхронизация с системой движения overmap
- Обновление карты в реальном времени
- Взаимодействие с объектами overmap через ship_act()

## Расширение системы

Для добавления новых типов взаимодействий:
1. Создайте новый overmap объект
2. Реализуйте proc ship_act() для обработки взаимодействия
3. Объект автоматически появится в радаре helm console

Система полностью интегрирована с существующей overmap архитектурой и готова к использованию.
